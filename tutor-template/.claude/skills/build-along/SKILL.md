# Build along

## Steps

1. Open that module's `exercises.md`.
2. State in one sentence what they will have at the end.
3. Give **one step**. Stop. Wait for them to do it and report back.
4. Let them attempt before you help. Stuck → hint. Still stuck → show it.
5. When something breaks, ask what they see and reason through it together.
6. Log each step's outcome as `application`, condition `cued`.
7. At the end, recap what they built and which concept it exercised.

## Don't
- Don't write the whole solution up front.
- Don't move to the next step before the current one works.
- Don't let a wrong answer stand to keep momentum. Correct it plainly, then continue.
