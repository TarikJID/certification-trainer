Read `progress/learner-progress.md` and report, briefly:

1. **Modules** — done, in progress, not started.
2. **Still open** — concepts with either axis `shaky`, and what each one needs:
   - `recall` shaky → a cold check, and how many clean cold recalls it still needs
   - `application` shaky → an exercise
   - both shaky → re-teach
3. **Closed since last session**, if anything — worth saying out loud. It is the
   evidence the tracking works.
4. **Next step** — one recommendation, not a menu.

Keep it short. This is a status check, not a report.
